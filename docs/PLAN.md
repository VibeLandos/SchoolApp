# План

## Сейчас

Рабочий каркас дневника: страница как в бумажном дневнике (номер, предмет, д/з в строке), добавление через нижние шиты, локальная база Room. Оценок нет и не планируются. Язык интерфейса: русский по умолчанию, английский из меню.

## Сделано

- Пустой Android-проект превращён в Compose-приложение
- Модель: уроки повторяются каждую неделю; домашка привязана к дате и номеру урока
- UI «тетрадь в обложке»: дни пн–сб, 8 строк, тап по клетке
- Вкладка всех заданий с фильтром и отметкой «сделано»
- К д/з можно прикрепить несколько фото (галерея, до 8)
- Шиты короче: урок без полей начала/конца (время из звонков каталога), кабинет по желанию
- Свайп между днями **текущей** недели (пн–сб); соседняя неделя — стрелками сверху (как разворот в бумажном дневнике)
- Английский интерфейс из бокового меню (русский по умолчанию, не от языка системы); строки в `strings.xml`
- Двойное нажатие «Дневник» в нижнем меню открывает сегодняшний день
- Превью фото декодируется в IO; фото д/з на странице группируются один раз, не фильтром в каждой строке
- Debug-сборка ставится и открывается на двух телефонах (Redmi Note 10S / POCO F5): `MainActivity` в Resumed, без FATAL в logcat
- Пейджер не пересоздаётся при смене недели (`key(weekDates)` убран); на странице дня нет `verticalScroll`, чтобы не спорить со свайпом
- Strong Skipping у Compose Compiler; release с R8 и debug-подписью — для проверки реальной скорости, не debug JIT
- Боковое меню с оформлением: обложка / система (обои слегка красят кожу, страница остаётся тетрадью) / ночь (темнее обложка, приглушённая бумага). Закрытие: свайп и жест назад; с края меню не открывается, чтобы не спорить с днями.
- Свайп на 120 Гц: пейджер без `beyondBoundsPageCount`, строки без `weight` (фиксированная колонка предмета), один жест на строку без ripple, мета урока не собирается заново каждый кадр.

## Ближайшее

Крупных пунктов в очереди нет. Не начинать фичи из блока «Будущее», пока нет макета или явной просьбы. Макет звонков и «сколько до конца» — ждём показа.

## Будущее (заказано)

- **Тёмная тема** — сделано: ночью та же тетрадь, темнее кожа, бумага не инвертируется.
- **Режим Material You** — сделано: обои слегка тонируют обложку, сетка уроков остаётся бумажной.
- **Боковое меню** — сделано для оформления и языка. Звонки — когда дойдём до этого пункта, не выдумывать экран звонков заранее.
- **Английский язык** — сделано: строки в `res/values` (русский по умолчанию) и `res/values-en`; переключатель в боковом меню. Записанные предметы и д/з в базе не переводятся.
- **Звонки один раз, не на каждый урок** — отдельное меню расписания звонков. На странице дня время берётся из этого расписания. Экран в духе «сколько до конца уроков»: макет будет позже, не выдумывать вёрстку заранее.
- В шите урока поля начала/конца после этого убрать или сделать необязательными.

## Идеи (не делать, пока не выбраны)

Имеет смысл именно для дневника, без журнала оценок:

- Уведомление «урок скоро кончится» / «осталось N минут до конца дня» — пара к экрану звонков.
- Виджет на рабочий стол: следующий урок + д/з на сегодня.
- Сфотографировать задание с камеры, не только из галереи.
- 5-дневная или 6-дневная неделя (без воскресенья, как сейчас, или с ним).
- Свои названия предметов и цвета строк.
- Каникулы / праздники: дни без сетки уроков.
- Поиск по тексту д/з.
- Локальный экспорт/бэкап (файл), без аккаунта.
- Напоминание вечером: что не сделано на завтра.
- Поворот/обрезка фото.
- Буфер «отмена» после случайного стирания строки.

Слабее стыкуется с «как бумажный дневник», лучше не в первую очередь: чаты, облако, аккаунты, оценки, ИИ.
