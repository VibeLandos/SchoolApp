# Changelog

Формат: дата — что изменилось и зачем. Новые записи сверху.

## 2026-09-06

- Сборка: Gradle user home задан в wrapper и в `.idea/gradle.xml`, чтобы Studio из Cursor не ходила в стёртый Temp/cursor-sandbox (mergeExtDex / цвета Material3).
- Сборка смотрит кэш Gradle в `C:/Users/Rinat/.gradle`, не в Temp/cursor-sandbox; Kotlin компилируется in-process — иначе assembleDebug падает на mergeExtDex и «Material3 color not found».
- Меню: отправить день или неделю текстом (выбор приложения) и вставить тот же текст. Домашка не участвует.
- Переключатель учебной недели в меню: 5 дней (пн–пт) или 6 (пн–сб).
- Страница дня без пустых 8 строк: уроки только те, что вписали, плюс кнопка «добавить урок» (номер в шите, можно 0).
- Вкладка «Сейчас»: дата берётся из того же секундного тикера, чтобы после полуночи день сменился без перезапуска.
- В план на будущее: дата на «Сейчас» после полуночи; пустой день с кнопкой «добавить урок» (не сетка 1–8); переключатель 5/6-дневной недели.
- Правило: после каждого законченного пункта сразу git-коммит, не копировать несколько фич.
- В план: импорт/экспорт расписания (день или неделя) текстом вместе со звонками; отправка через выбор приложения, не файлом.

- После обновления Android Studio 2026.1.4 Gradle JDK переведён на JBR 21: у новой Studio `jbr` — Java 25 (Gradle 8.6 её не берёт), а старый `jbr` в Program Files сломан (java 17 + release 25).

- В расписании звонков выбранный день выделен плашкой и подписан полностью. Кнопку «Как у недели» убрали.

- Английский язык: строки вынесены из Composable в `res/values/strings.xml`, перевод в `values-en`. В меню — Русский / English; по умолчанию русский даже на английском телефоне. Даты и список предметов следуют языку интерфейса, записи в базе не переводятся.

- Свайп дней на 120 Гц: `HorizontalPager` больше не держит соседние страницы в мере; у строк урока убран двухпроходный `weight`, клики схлопнуты в один жест без ripple, подпись времени/кабинета кэшируется — меньше работы на кадр при движении пальца.
- Меню закрывается свайпом и жестом назад (открывается только гамбургером). Темы приведены к тетради: система тонирует обложку, ночь не красит страницу в чёрное.
- Оформление из бокового меню: обложка / Material You / ночная тетрадь. Drawer без жеста с края, чтобы не перехватывать свайп дней. Палитра страницы через `LocalDiaryPalette`, не только MaterialScheme.
- Свайп внутри недели без лагов от пересоздания: `HorizontalPager` на 6 дней, без `key(weekDates)`; недели только стрелками. Убран `verticalScroll` со страницы дня. Strong Skipping + release с R8/debug-подписью, чтобы мерить скорость не по debug JIT.
- Проверен запуск debug APK на двух подключённых телефонах: установка, `MainActivity` на экране, без краша.
- Переход на соседнюю неделю сажает на край: свайп/стрелка вперёд — на понедельник следующей, назад — на субботу предыдущей. Пейджер из 8 лёгких страниц (края + пн–сб), без тысяч страниц и без декода фото.
- Листание больше не должно тормозить: строки без IntrinsicSize и без декода фото на странице (подпись «N фото»).
- Декодирование превью фото ушло с UI-потока (`produceState` + `Dispatchers.IO`). На странице дневника фото группируются через `groupBy`, без фильтра в каждой из 8 строк.
- В `gradle.properties` указан JDK Android Studio (`jbr`): системная Java 25 ломает Gradle 8.6.
- Добавлены `docs/MAP.md`, `docs/PLAN.md`, `docs/CHANGELOG.md` и правило `.cursor/rules/project.mdc`, чтобы агент опирался на карту, а не сканировал весь проект.
- Собран первый дневник на Compose: страница дня (№ / предмет / д/з), шиты добавления урока и домашки, Room (`Lesson` по дню недели, `Homework` по дате), вкладки «Дневник» и «Задания».
- Проект переведён с пустого шаблона без Activity на Kotlin + Compose + Material3 + Navigation + Room.
