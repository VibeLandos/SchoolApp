# Дневник (SchoolApp)

Android-приложение для школьников: удобное расписание уроков по дням недели, домашние задания на конкретные даты и умное расписание звонков.

## Версия 2.5 (Исправление жеста «Назад» на Android 14)

- **Надёжная обработка жеста «Назад» с открытой клавиатурой:**
  - Отключён системный перехват жеста назад шторкой (`shouldDismissOnBackPress = false`), пока открыта экранная клавиатура или активно текстовое поле ввода.
  - На Android 13/14 жест «Назад» теперь гарантированно закрывает саму клавиатуру, не закрывая плашку создания/редактирования урока.
  - Повторный жест назад после скрытия клавиатуры закрывает плашку.

## Версия 2.4 (Исправление положения кнопки + и закрытие клавиатуры)

- **Кнопка «+» (FAB):** возвращена на своё штатное место (16dp над панелью нижней навигации) на экранах «Дневник» и «Задания». Устранено избыточное смещение вверх.
- **Интеллектуальное закрытие клавиатуры в шторках создания урока и задания:**
  - При нажатии на пустое место внутри шторки добавления урока (`EditLessonSheet`) или домашнего задания (`EditHomeworkSheet`) теперь плавно скрывается экранная клавиатура и снимается фокус ввода.
  - При нажатии кнопки «Назад» (или жеста «Назад») при открытой клавиатуре скрывается только клавиатура, а сама шторка добавления остаётся открытой. Повторное нажатие «Назад» закрывает саму шторку.

## Возможности

- **Расписание недели:** удобный свайп между днями недели, отображение времени уроков, кабинетов и прикреплённых заданий.
- **Звонки:** гибкая настройка уроков и перемен, быстрый мастер настройки на всю неделю и переопределение отдельных дней.
- **Вкладка «Сейчас»:** таймер до звонка, прогресс текущего урока и уроков на день, расчёт времени до конца учебного дня и года.
- **Задания:** список домашних заданий по датам, фильтрация (Все / Сделано / Не сделано), прикрепление фотографий (до 8 штук).
- **Импорт и экспорт:** возможность поделиться расписанием дня или недели текстом и вставить его на другом устройстве.
- **Оформление:** Material You с адаптивными цветами обоев (Dynamic Color) или 4 акцентными палитрами, тёмная / светлая темы, а также режим Liquid Glass.
- **Обновления:** встроенная автоматическая проверка новых версий с GitHub Releases.

## Сборка

- JDK: Java 17 / 21
- Gradle: 8.6
- Android SDK: compileSdk 34, minSdk 24

Сборка debug APK:
```bash
./gradlew assembleDebug
```

Сборка release APK:
```bash
./gradlew assembleRelease
```
