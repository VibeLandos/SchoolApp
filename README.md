# Дневник (SchoolApp)

Android-приложение для школьников: удобное расписание уроков по дням недели, домашние задания на конкретные даты и умное расписание звонков.

## Версия 1.6

- **Исправление сохранения расписания и звонков:**
  - Устранено жесткое ограничение на 8 уроков в алгоритме звонков: теперь приложение корректно сохраняет и восстанавливает любое количество звонков (5, 6, 7, 8 и более) без сброса на дефолтные значения при перезапуске.
  - Изменение времени звонков в общем расписании сразу применяется ко всей неделе.
  - Добавлены функции «Применить ко всей неделе» и «Сбросить к звонкам недели» для отдельных дней.
  - Все операции сохранения расписания (`Lesson`) и домашних заданий (`Homework`) защищены `NonCancellable + Dispatchers.IO` для надёжной фиксации транзакций Room.
  - Настройки `ThemeSettings` сохраняются синхронно (`commit()`), предотвращая потерю данных при выгрузке приложения из памяти.
  - Исправлен импорт дня расписания: день недели теперь берётся напрямую из формата экспорта (`dow:X`).
  - Исправлен выбор номера урока: текущий номер больше не блокируется при редактировании.

## Возможности

- **Расписание недели:** удобный свайп между днями недели, отображение времени уроков, кабинетов и прикреплённых заданий.
- **Звонки:** гибкая настройка уроков и перемен, быстрый мастер настройки на всю неделю и переопределение отдельных дней.
- **Вкладка «Сейчас»:** таймер до звонка, прогресс текущего урока и уроков на день, расчёт времени до конца учебного дня и года.
- **Задания:** список домашних заданий по датам, фильтрация (Все / Сделано / Не сделано), прикрепление фотографий (до 8 штук).
- **Импорт и экспорт:** возможность поделиться расписанием дня или недели текстом и вставить его на другом устройстве.
- **Оформление:** Material You с адаптивными цветами обоев (Dynamic Color) или 4 акцентными палитрами, тёмная / светлая темы, а также режим Liquid Glass.
- **Обновления:** встроенная автоматическая проверка новых версий с GitHub Releases.

## Сборка

- JDK: Java 17 / 21
- Gradle: 8.6
- Android SDK: compileSdk 34, minSdk 24

Сборка debug APK:
```bash
./gradlew assembleDebug
```

Сборка release APK:
```bash
./gradlew assembleRelease
```
