# Дневник (SchoolApp)

Android-приложение для школьников: удобное расписание уроков по дням недели, домашние задания на конкретные даты и умное расписание звонков.

## Версия 2.1 (Значки предметов)

- **Интеграция 12 векторных значков предметов по дизайн-макету MD3:**
  - Счёты / Абак (`abacus`) — Математика, Алгебра, Геометрия
  - Атом (`atom`) — Физика, Естествознание
  - Компьютер (`computer`) — Информатика, Программирование
  - Книга (`book`) — Русский язык, Литература, Чтение
  - Глобус (`globe`) — География, История, Обществознание
  - Языки (`language`) — Иностранные языки (Английский, Немецкий и др.)
  - Колба (`flask`) — Химия, Биология
  - Мяч (`ball`) — Физкультура, Спорт
  - Ручка / Перо (`pen`) — Черчение, Технология, Письмо
  - Палитра (`palette`) — ИЗО, Рисование, Искусство
  - Музыка (`music`) — Музыка, Хор
  - Дневник (`diary`) — Общее, Классный час, ОБЖ
- **Автоматическое назначение по ключевым словам:** при создании уроков значок предмета распознается автоматически.
- **Нижний диалог «Значок предмета» (BottomSheet):** интерактивная сетка 4×3 по макету с 72dp кнопками, скруглением 24dp, подсветкой выбранного значка и кнопками «Отмена» и «Готово».
- **Значки во всех разделах приложения:**
  - В карточках уроков на вкладке **Дневник** (контейнер 52×52dp, форма 16dp).
  - В карточках задач на вкладке **Задания** (рядом с чекбоксом).
  - В карточках успеваемости на вкладке **Оценки** (рядом с названием предмета).
  - В диалоге добавления/редактирования урока с возможностью мгновенной смены значка.
- **Персистентное сохранение:** индивидуальный выбор значка для любого предмета сохраняется в настройках и обновляет интерфейс на лету.

## Версия 2.0 (Material Design 3 Redesign)

- **Полный редизайн по макету Material Design 3:**
  - 4 главные вкладки навигации: **Дневник**, **Задания**, **Оценки**, **Профиль**.
  - MD3 палитра Purple (`#6750A4` / `#D0BCFF`) с органическими блоб-значками (`border-radius: 42% 58% 62% 38% / 45% 40% 60% 55%`).
  - **Дневник:** адаптивный герой-баннер ("Сегодня N уроков", статус урока/перемены или д/з на завтра), горизонтальный выбор дней свайпами, карточки уроков с временем, д/з/кабинетом и оценками-блобами, FAB добавления урока.
  - **Задания:** фильтрация ("Все", "Сегодня", "Просрочено"), карточка общего прогресса ("Выполнено X из Y"), круглые чекбоксы и Extended FAB.
  - **Оценки:** общая карточка со средним баллом за четверть крупным шрифтом (72sp), разбивка по предметам, журнал оценок и средний балл.
  - **Профиль:** экран настроек и профиля ученика — звонки, учебная неделя, учебный год, темы, палитры, шаринг и импорт расписания.
  - Персистентное хранилище оценок в Room (`Grade`, `GradeDao`, `MIGRATION_3_4`).
  - Исправлен CI/CD workflow в GitHub Actions для автосборки релизных APK.

## Версия 1.6

- **Исправление сохранения расписания и звонков:**
  - Устранено жесткое ограничение на 8 уроков в алгоритме звонков: теперь приложение корректно сохраняет и восстанавливает любое количество звонков (5, 6, 7, 8 и более) без сброса на дефолтные значения при перезапуске.
  - Изменение времени звонков в общем расписании сразу применяется ко всей неделе.
  - Добавлены функции «Применить ко всей неделе» и «Сбросить к звонкам недели» для отдельных дней.
  - Все операции сохранения расписания (`Lesson`) и домашних заданий (`Homework`) защищены `NonCancellable + Dispatchers.IO` для надёжной фиксации транзакций Room.
  - Настройки `ThemeSettings` сохраняются синхронно (`commit()`), предотвращая потерю данных при выгрузке приложения из памяти.
  - Исправлен импорт дня расписания: день недели теперь берётся напрямую из формата экспорта (`dow:X`).
  - Исправлен выбор номера урока: текущий номер больше не блокируется при редактировании.

## Возможности

- **Расписание недели:** удобный свайп между днями недели, отображение времени уроков, кабинетов и прикреплённых заданий.
- **Звонки:** гибкая настройка уроков и перемен, быстрый мастер настройки на всю неделю и переопределение отдельных дней.
- **Вкладка «Сейчас»:** таймер до звонка, прогресс текущего урока и уроков на день, расчёт времени до конца учебного дня и года.
- **Задания:** список домашних заданий по датам, фильтрация (Все / Сделано / Не сделано), прикрепление фотографий (до 8 штук).
- **Импорт и экспорт:** возможность поделиться расписанием дня или недели текстом и вставить его на другом устройстве.
- **Оформление:** Material You с адаптивными цветами обоев (Dynamic Color) или 4 акцентными палитрами, тёмная / светлая темы, а также режим Liquid Glass.
- **Обновления:** встроенная автоматическая проверка новых версий с GitHub Releases.

## Сборка

- JDK: Java 17 / 21
- Gradle: 8.6
- Android SDK: compileSdk 34, minSdk 24

Сборка debug APK:
```bash
./gradlew assembleDebug
```

Сборка release APK:
```bash
./gradlew assembleRelease
```
